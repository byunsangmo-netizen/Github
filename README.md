# Stock Agent Pro v3

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 바탕화면 아이콘 만들기
압축을 푼 폴더에서 `바탕화면_아이콘_만들기.bat`을 더블클릭하세요.  
바탕화면에 `Stock Agent Pro` 바로가기가 만들어집니다.

바로 실행만 하려면 `run_stock_agent.bat`을 더블클릭해도 됩니다.

## v3 변경사항
- 분석란 문장을 요청한 형식으로 고정했습니다.
- 관심종목은 오늘 저장된 score가 높은 순서로 자동 재배열됩니다.
- 전체 폰트를 약 20% 작게 조정했습니다.
- 바탕화면 실행 아이콘 생성용 배치 파일을 추가했습니다.
