# Stock Agent Pro V14.1

실제 투자 포트폴리오 모드와 매도 타이밍 엔진을 강화한 버전입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## V14.1 변경점
- 매수금액과 수량만 입력하면 매수가는 자동 계산됩니다.
- 검색/분석 시점 현재가는 30분봉 최신값을 우선 사용합니다.
- 실제 투자 포트폴리오 모드: MU, NVDA, AMD, TSLA, ORCL, SpaceX 기본 불러오기 버튼 추가.
- 실제투자 체크 종목은 관심그룹 `매수 종목`에 자동 등록됩니다.
- 오늘 브리핑에서 보유종목 중심 AI 유지/매도 판단을 먼저 확인합니다.
- 데이터 요청은 버튼 클릭 시에만 수행하도록 유지합니다.
